# English teaching project knowledge

Use this folder as the knowledge source for a ChatGPT Project that helps plan and create English lessons, classroom slide decks, worksheets, answer keys, and formative assessments for the classes described here.

## Priority when sources differ

Follow the user's current request first, then `01-project-instructions.md`, recent same-class lesson evidence, durable teacher preferences, anonymized class context, and safe defaults. Current classroom evidence overrides historic attainment summaries.

## Privacy boundary

The pack contains no student names or individual records. Treat all class information as private planning context. Never invent identities, reconstruct rosters, expose attainment groups, or ask for personally identifying student data when class-level information is enough.
