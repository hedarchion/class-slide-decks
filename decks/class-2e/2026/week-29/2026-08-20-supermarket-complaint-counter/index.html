STEP 1 · MAKE A COMPLAINT

1. COMPLAIN — start strong, stay polite

✗ “This is bad.” ✗ “I don't like this.” ✗ “Give money!” What's the problem? How can we say it better?

LANGUAGE BANK · A2 CORE

Excuse me, there's a problem with ______.

…with this milk.

I'm sorry, but this ______ is ______.

…but this bottle is leaking.

I bought this ______, but ______.

…but the price was wrong.

USEFUL COLLOCATIONS — tap each one

Micro-practice — say it together:
“I'm sorry, but this milk is expired.” “I'm sorry, but this packaging is damaged.” “I'm sorry, but this price is wrong.”
STEP 2 · GIVE A REASON

2. Don't stop at the complaint.

Which complaint is stronger? Why?
✓ B — a reason shows why it matters. COMPLAINT + because/so/but → REASON

LANGUAGE FRAMES

The problem is ______ because ______.

I can't use / eat / drink it because ______.

I think I should get ______ because ______.

CONNECTORS + EXAMPLES

because · so · but

I can't drink it because it has expired.

I paid RM10, but the shelf price was RM8.

The bottle is leaking, so I'd like another one.

STEP 3 · CUSTOMER SERVICE RESPONDS

3. Customer service responds

First acknowledge. Then ask. Then offer.

ACKNOWLEDGE

I'm sorry about that.

I understand the problem.

Let me check.

ASK

Do you have the receipt?

When did you buy it?

What's wrong with the product?

Could you show me the product?

OFFER

We can replace it.

We can give you a refund.

I can exchange it for you.

Would you like another one?

QUICK REACTION — the customer says:
“I bought this juice this morning, but the bottle is leaking.”
✓ B — acknowledge first, then ask to check the evidence.
STEP 4 · THE ARGUMENT BEGINS

4. The argument begins

Customer wants a refund. Customer service can only offer an exchange.
I'd like a refund, please. → I'm sorry, but we can only replace the product. What can the customer say now?
✗ You're wrong! That's stupid! Give me my money!
✓ “I understand, but I don't think that's fair because the product was already damaged.”

POLITE DISAGREEMENT · A2 CORE

I understand, but ______.

I'm sorry, but I don't agree.

But the problem is ______.

Could you ______ instead?

EXTENSION · A2-HIGH / B1

I see your point, but ______.

I don't think that's fair because ______.

I'd prefer ______ because ______.

Would it be possible to ______?

PUT IT TOGETHER · C + R + S

Build an argument — Claim · Reason · Solution

CLAIM — what do you want?
“I think I should get a refund.”
REASON — why?
“…because the product has expired.”
SOLUTION — what should happen?
“Could you refund my money, please?”
“I think I should get a refund because the product has expired. Could you refund my money, please?”
Now try — 🎧 headphones · one side doesn't work · replacement:
“I think I should get a replacement because one side doesn't work.”
Same shape, different products: expired milk · rotten apples · wrong price on biscuits. The structure does the work.
