## Interpretation

Use the pattern of errors, not only the total. If Part A is weak, reteach phrase partners. If Part B is weak, revisit action-to-phrase meaning. If Part C is weak, use the Phrase Machine and contrast natural/unnatural combinations. If Part E is much lower than Parts A–D, provide more spaced retrieval.

This is an unpiloted formative worksheet. It can guide immediate reteaching but cannot establish statistical reliability or broad mastery.
